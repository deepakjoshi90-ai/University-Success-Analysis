# 🎓 University Success Analysis Dashboard | Power BI

## 📌 Project Overview

The **University Success Analysis Dashboard** is a data analytics project developed using Microsoft Power BI to explore university performance, student enrollment, ranking systems, and international education trends across different countries.

The dashboard transforms university data into interactive visualizations to help users explore patterns and compare key performance indicators.

## 🎯 Project Objectives

- Analyze the number of universities across different countries.
- Identify countries with the highest female student enrollment.
- Compare university scores across different ranking systems.
- Explore student–staff ratios and university performance.
- Analyze international student enrollment trends over time.
- Examine the relationship between university scores and international student percentages.
- Compare the criteria used by different university ranking systems.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** — Dashboard development and visualization
- **Power Query** — Data preparation and transformation
- **Data Modeling** — Organizing data for analysis
- **Interactive Filters & Slicers** — Exploring data dynamically

## 📊 Dashboard Features

- KPI cards displaying key metrics, including total universities and total students.
- Country-wise university analysis.
- Female student enrollment analysis.
- Comparison of university ranking systems and scores.
- Student–staff ratio analysis.
- International student trend analysis.
- Interactive filters for exploring university and ranking data.

## 🔍 Key Analysis Areas

1. University distribution by country.
2. Female student enrollment across countries.
3. University scores by ranking system.
4. Student–staff ratio comparisons.
5. International student trends by year.
6. Relationship between ranking scores and student demographics.
7. Ranking criteria comparison across ranking systems.
